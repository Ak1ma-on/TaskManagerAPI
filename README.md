# TaskManagerAPI

Простое API со стандартными CRUD операциями для управления списком задач с поддержкой базы данных

## Структура
- `Controllers/` | Контроллеры для конечных точек
- `Data/` | Контекст базы данных
- `Migrations/` | Миграции
- `Models/` | Данные, бизнес-логика, DTO-объекты
- `Services/` | Классы для работы с данными

## Функции
- Добавить задачу в список (HttpPost)
- Обновить задачу (HttpPut)
- Получить задачу по ID (HttpGet)
- Получить весь список задач (HttpGet)
- Удалить задачу по ID (HttpDelete)

## Технологии
- .NET 9.0.314
- ASP.NET Core 9.0.16
- C# 13
- EF Core 10.0.8

## Установка
1. Клонировать репозиторий
2. Применить миграции: `dotnet ef database update`
3. Запустить: `dotnet run`
