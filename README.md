# TaskManagerAPI

Простое API со стандартными CRUD операциями для управления списком задач

## Функции
- Добавить задачу в список (HttpPost)
- Обновить задачу (HttpPut)
- Получить задачу по ID (HttpGet)
- Получить весь список задач (HttpGet)
- Удалить задачу по ID (HttpDelete)

## Технологии
- .NET 9.0.314
- ASP.NET Core 9.0.16
- C# 13

## Запуск
dotnet run
